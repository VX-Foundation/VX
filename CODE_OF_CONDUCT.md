# VX Community Code of Conduct

VX contributors must help maintain a professional, welcoming, and technically rigorous community.

## Expected behavior

- Treat people with respect regardless of experience, background, identity, or role.
- Critique ideas and code without attacking people.
- Give reproducible evidence for technical claims.
- Respect security embargoes, privacy, licenses, and repository policies.
- Accept maintainer decisions made through the documented RFC and review processes.

## Unacceptable behavior

Harassment, threats, discrimination, doxxing, sexualized conduct, deliberate disruption, plagiarism, malicious code, concealed conflicts of interest, and publication of private vulnerability details are not accepted.

## Enforcement

Report conduct concerns through the private contact method configured on the canonical GitHub repository. Maintainers may edit or remove content, restrict participation, or permanently ban accounts when necessary. Security reports must follow `SECURITY.md`.
