# VX Support

## Release lines

- `canary`: experimental builds with no support guarantee.
- `next`: the active VX 0.x stabilization line. Security fixes and migration guidance are provided for the latest published `next` release.
- `latest`: reserved for VX 1.0 and later. It remains blocked until every mandatory stable-release criterion is satisfied.

## Getting help

Use GitHub Discussions for design and usage questions and GitHub Issues for reproducible defects. Include the VX package versions, Node version, operating system, browser or deployment target, a minimal reproduction, and the exact diagnostics.

Do not use public issues for vulnerabilities. Follow `SECURITY.md`.
