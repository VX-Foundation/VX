# Framework-native fixture contract

Each framework directory must contain a `native-runner.mjs` maintained against the exact package versions generated by `scripts/prepare.mjs`. The module must statically import its declared runtime package and export `createNativeBenchmarkAdapter(context)`.

The adapter returns `{ framework, execute, cleanup? }`. Every `execute` result contains a non-negative metric and evidence fields:

- `native-runtime`: exact framework identifier;
- `scenario-contract`: scenario being executed;
- `rendered-output`: SHA-512 or equivalent digest of the actual rendered result;
- `raw-artifact`: relative path to a retained trace, screenshot, heap snapshot, bundle manifest, server payload, or build log.

Browser scenarios must execute production framework code in a pinned browser. Build scenarios must invoke each framework's documented production build. SSR, streaming, hydration and islands must validate equal output and behavior before measurements become rankable. A shared JavaScript loop, mocked renderer or hand-written DOM fallback is prohibited.
