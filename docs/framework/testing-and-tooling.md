# Testing and Tooling

The official testing package covers units, components, DOM, SSR, hydration, routes, actions, endpoints, browsers, accessibility, visual regression, and performance budgets.

The CLI provides project creation, development, build, preview, test, check, format, lint, inspect, migration, package operations, doctor, and publish workflows. The LSP, VS Code extension, and Browser DevTools consume the same public diagnostics and graph contracts.
