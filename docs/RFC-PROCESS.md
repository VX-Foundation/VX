# RFC Process

The normative RFC workflow is in `rfcs/README.md`.

An RFC is mandatory for language syntax or semantics, public API additions or removals, package format changes, compiler/runtime ownership changes, security-boundary changes, compatibility policy, or stable support guarantees.

RFC review must evaluate implementation cost, invalid behavior, diagnostics, accessibility, security, performance, migration, testing, documentation, and SemVer impact. Accepted RFCs are referenced by implementation pull requests and release notes.
