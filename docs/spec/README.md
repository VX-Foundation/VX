# VX Language Specification

This directory is the normative specification for the VX language and framework source model.

Normative keywords such as **MUST**, **MUST NOT**, **SHOULD**, and **MAY** have their usual requirements meaning. A conforming compiler must implement every requirement marked as normative and must emit diagnostics for invalid source instead of silently changing its meaning.
