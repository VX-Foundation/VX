# VX 0.1 Specification Freeze

The VX language and framework specification is frozen for the 0.1 stabilization line as of 2026-07-30.

A frozen specification does not mean that VX 1.0 has been released. It means changes to syntax, semantics, ownership, client/server behavior, diagnostics, module contracts, or conformance requirements must use the RFC process and include compatibility and migration analysis.

The normative file set and SHA-256 digests are recorded in `release/spec-freeze.json`. Editorial corrections that do not alter meaning may be accepted without resetting stabilization. Semantic changes require an accepted RFC and a regenerated freeze manifest.
