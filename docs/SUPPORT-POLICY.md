# Support Policy

## VX 0.x

The latest `next` release receives security fixes and critical defect corrections. Earlier 0.x release candidates may be superseded without backports. Canary builds receive no support guarantee.

## VX 1.x and later

After stable release, VX supports the latest minor release and the immediately previous minor for critical security fixes during a published transition window. Patch releases remain API compatible.

## Runtime support

The VX 0.2 line supports Node.js 22 and 24 LTS. Browser support covers current stable Chromium, Firefox, and WebKit releases validated by the official Playwright matrix. Adapter support is stated per release and requires conformance tests.
