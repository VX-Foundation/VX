# Changelog

All notable VX changes are documented here. The project follows Semantic Versioning and uses Changesets for package-level release notes.

## 0.1.0 — Unreleased

- Migrated the development toolchain to pnpm 11.17.0, replaced the removed `packageManagerStrictVersion` setting with `pmOnFail`, moved pnpm project settings to `pnpm-workspace.yaml`, and aligned generated templates and release gates with pnpm 11.

Initial public unstable line containing the language, compiler, runtime, router, server platform, data and forms packages, build adapters, tooling, package/plugin platform, testing infrastructure, documentation, and official conformance applications delivered through Phases 1–22.

This version is intended for `canary` and `next` evaluation. It is not VX 1.0 and does not carry stable compatibility guarantees.
